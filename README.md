# Benedetta - The Study Club

Static website for Benedetta. Deploy this branch on Vercel with the Other preset, no build or install command, and the root output directory.

All app assets and Mozilla PDF.js are included in index.html. PDF.js is licensed under Apache 2.0; see PDFJS-LICENSE.txt.

This publication branch contains no personal PDFs or secrets. Imported notes are processed and stored in the visitor browser, with IndexedDB. Planner, goals and study progress are local to that browser.
